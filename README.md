# ⚽ לוח משחקים — אפליקציה ואתר

- 🌐 **האתר:** https://i0533101089-debug.github.io/luach-mischakim/
- 📲 **האפליקציה לאנדרואיד (APK):** https://github.com/i0533101089-debug/luach-mischakim/releases/latest

הכל נבנה **בחינם, בענן של GitHub**, אוטומטית אחרי כל שינוי בקבצים.

---

## התקנה בטלפון

1. מהטלפון פותחים את הקישור של האפליקציה למעלה ומורידים את **luach-mischakim.apk**.
2. פותחים את הקובץ ← מתקינים (אם הטלפון שואל — מאשרים "התקנה ממקורות לא ידועים" לדפדפן).

---

## העברת הנתונים מהמחשב לאפליקציה

1. בגרסה שבמחשב: **⚙️ ניהול ליגות ומאגר קבוצות ← 📤 יצוא גיבוי מלא**.
2. שולחים את קובץ ה-JSON לטלפון (וואטסאפ לעצמך / מייל / דרייב).
3. באפליקציה: **⚙️ ← 📥 יבוא נתונים מקובץ גיבוי** ← בוחרים את הקובץ.

הגיבוי כולל את הליגות, המאגר, הלוח, מילון הניקוד והליגות המועדפות.

---

## עדכון האפליקציה בעתיד

מחליפים את הקובץ `www/index.html` במאגר (Add file ← Upload files) ← הבנייה רצה לבד ←
מורידים את ה-APK החדש מ-Releases ומתקינים **מעל** הקיים. הנתונים נשמרים
(החתימה קבועה — זה מה שהקובץ `app-signing.keystore` עושה, אל תמחק אותו).

---

## מה יש באפליקציה

- 📡 **משיכה אוטומטית מ-365Scores** לשבוע הקרוב, רק מהליגות שבחרת.
- ✅ בוחרים במסך אחד אילו משחקים נכנסים להקראה.
- ✨ **ניקוד מלא**: תבנית, ימים, תאריכים, שעות (כולל 20:05 וכד'), ליגות וקבוצות.
- 📖 **מילון ניקוד** — שם שנוקד פעם אחת נשמר לתמיד. שמות חדשים מנוקדים אוטומטית (הנקדן של דיקטה) ומוצגים לבדיקה.
- 📋 העתקה / 📤 שליחה ישירה לבוט או לוואטסאפ.
- 🔊 הקראה בקול של הטלפון (צריך קול עברית ב"שירותי דיבור של Google").
- 🎙️ הקלטת MP3 — זמינה רק בגרסת המחשב (Chrome).

## קבצים בפרויקט

| קובץ | מה זה |
|---|---|
| `www/index.html` | האפליקציה עצמה (אותו קובץ שעובד גם בדפדפן במחשב) |
| `capacitor.config.json` | הגדרות האפליקציה (שם, חיבור ישיר לאינטרנט) |
| `.github/workflows/build-apk.yml` | הוראות הבנייה בענן (APK + אתר) |
| `android-res.zip` | אייקון ומסך פתיחה |
| `app-signing.keystore` | מפתח החתימה הקבוע של האפליקציה |
