# ⚽ לוח משחקים אוטומטי להקראה — אתר ואפליקציה

- 🌐 **האתר:** https://i0533101089-debug.github.io/luach-mischakim/
- 📲 **האפליקציה לאנדרואיד (APK):** https://github.com/i0533101089-debug/luach-mischakim/releases/latest/download/luach-mischakim.apk

אותו קובץ (`www/index.html`) הוא גם האתר וגם האפליקציה. כל שינוי בו במאגר בונה אוטומטית אתר מעודכן ו-APK חדש.

## מה בפנים
- 📡 משיכה מ-365Scores של השבוע הקרוב — רק 44 התחרויות ו-4 הקבוצות שאתה עוקב אחריהן (ניתן לשנות ב"ניהול").
- ✨ ניקוד מלא: התבנית, ימים, תאריכים, שעות (כל דקה), ליגות וקבוצות — כולל כל השמות המנוקדים שלך.
- 🆕 שם חדש שמגיע מ-365 מנוקד אוטומטית (הנקדן של דיקטה) ומוצג לבדיקה פעם אחת — ואז נשמר לתמיד.
- ☁️ **סנכרון ענן:** הנתונים נשמרים בקובץ `data/luach-data.json` במאגר הזה ומסתנכרנים בין המחשב לטלפון — בלי גיבויים.
- 📋 העתקה / 📤 שליחה לבוט, 🔊 הקראה, 🎙️ MP3 (גם באפליקציה, ישירות ממנוע הדיבור של הטלפון).

## הפעלת הסנכרון (פעם אחת בכל מכשיר)
1. יצירת מפתח: https://github.com/settings/tokens/new?scopes=public_repo&description=luach-mischakim-sync
   — ב-Expiration בוחרים **No expiration** ← **Generate token** ← מעתיקים (מתחיל ב-ghp_).
2. באתר / באפליקציה: לוחצים על **☁️** למעלה ← מדביקים ← **שמור והתחבר**.

## התקנה בטלפון
פותחים את קישור ה-APK מהטלפון ← מתקינים (אם נשאל — מאשרים "התקנה ממקורות לא ידועים").
גרסה חדשה מותקנת מעל הקודמת והנתונים נשמרים (בגלל `app-signing.keystore` — לא למחוק).

## קבצים
| קובץ | מה זה |
|---|---|
| `www/index.html` | האפליקציה עצמה |
| `android-src/` | מנוע ההקראה בעברית לאנדרואיד (כולל יצירת MP3) |
| `capacitor.config.json` | הגדרות האפליקציה |
| `.github/workflows/build-apk.yml` | הבנייה בענן (APK + אתר) |
| `android-res.zip` | אייקון ומסך פתיחה |
| `app-signing.keystore` | מפתח החתימה הקבוע של האפליקציה |
| `data/luach-data.json` | הנתונים שלך (נוצר אוטומטית בסנכרון הראשון) |
